# G2 Tecnologia

Site institucional da G2 Tecnologia, com foco em automacao industrial, IA, dados e conversao via WhatsApp.

## Stack

- Vite
- JavaScript
- CSS
- GSAP

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Deploy

O projeto esta configurado para deploy na Vercel com:

- Build Command: `npm run build`
- Output Directory: `dist`
- Production Branch: `main`
