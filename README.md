# G2 Tecnologia

Site institucional da G2 Tecnologia, com foco em automacao industrial, IA, dados e conversao via WhatsApp.

## Stack

- Vite
- JavaScript
- CSS
- GSAP

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Deploy

O projeto esta configurado para deploy na Vercel com:

- Build Command: `npm run build`
- Output Directory: `dist`
- Production Branch: `main`

## Producao

- GitHub: https://github.com/Cesartcsd/g2.com
- Vercel: https://site-g2-beta.vercel.app
- Projeto Vercel: `cesar-dias-projects/site-g2`

Cada push em `main` dispara um deploy automatico na Vercel.

## Dominio

O dominio final previsto no HTML e `g2techbrasil.com.br`.

Antes de trocar DNS, confirme a janela de virada e a propriedade do dominio. Hoje o dominio ainda deve ser apontado manualmente para a Vercel quando a troca for autorizada.
